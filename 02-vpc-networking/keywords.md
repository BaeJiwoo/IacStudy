# 핵심 용어

다음 용어를 자신의 말로 정의하고, 비슷한 개념과 차이를 예제로 설명한다.

- CIDR
- VPC
- Subnet
- Route Table
- Internet Gateway
- NAT Gateway
- VPC Endpoint
- Security Group
- Network ACL
- Transit Gateway
- PrivateLink
- Route 53 Resolver
- Site to Site VPN
- Direct Connect
- VPC IPAM

전체 과정의 연결은 [루트 용어집](../glossary.md)에서 확인한다.
