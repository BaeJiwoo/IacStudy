# 핵심 용어

다음 용어를 정의하고 서로의 관계를 그림이나 예제로 설명한다.

- Template, Stack, Resource
- Logical ID, Physical ID
- Parameter, Mapping, Condition, Output
- `Ref`, `Fn::Sub`, `Fn::GetAtt`
- Dependency, `DependsOn`
- Stack Event, Rollback
- DeletionPolicy, UpdateReplacePolicy
- Capabilities

전체 정의는 [루트 용어집](../glossary.md)과 함께 확인한다.
