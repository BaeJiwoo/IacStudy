# 핵심 용어

- Change Set, Replacement, Import Change Set
- Stack Policy, Termination Protection
- Drift Detection, Import, Resource Scan
- Rollback, `UPDATE_ROLLBACK_FAILED`, Continue Update Rollback
- Nested Stack, Cross Stack Reference
- StackSets, Administrator Account, Target Account
- Service Managed Permission, Self Managed Permission
- Deployment Targets, Operation Preferences, Failure Tolerance
- CloudFormation Guard, Hook, Registry Extension

전체 정의는 [루트 용어집](../glossary.md)에서 확인하고, 각 항목이 예방 통제인지 탐지 통제인지 분류한다.
