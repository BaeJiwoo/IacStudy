# 최종 프로젝트 시연 스크립트

## 준비

- 사용할 AWS Account와 Region:
- 예상 비용:
- 시연 후 삭제할 리소스:
- 현재 Git Commit:

## 시나리오 1 정상 Development 배포

1. 인프라 요청을 제출한다.
2. Pull Request와 Plan을 확인한다.
3. 정책 통과를 확인한다.
4. Apply를 실행한다.
5. AWS 리소스와 배포 상태를 확인한다.

## 시나리오 2 보안 정책 거부

1. 공개 관리 포트 또는 암호화 누락을 요청한다.
2. 정책 실패와 수정 안내를 확인한다.
3. AWS에 리소스가 생성되지 않았음을 확인한다.

## 시나리오 3 승인 후 Commit 변경

1. Production Plan을 승인한다.
2. Commit을 변경한다.
3. 이전 승인으로 Apply가 거부되는지 확인한다.

## 시나리오 4 Drift와 복구

1. Console에서 관리 리소스를 변경한다.
2. Drift 작업과 알림을 확인한다.
3. 코드 반영 또는 원상 복구를 수행한다.

## 정리

- [ ] 모든 실습 리소스를 삭제했다.
- [ ] State와 실제 AWS 리소스가 일치한다.
- [ ] 비용 발생 리소스가 남지 않았다.
- [ ] 시연 결과와 개선 사항을 기록했다.
