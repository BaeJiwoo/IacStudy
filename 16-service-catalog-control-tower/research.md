## 조사 질문

1. Product, Provisioning Artifact, Portfolio와 Provisioned Product의 관계는 무엇인가.
2. Launch Constraint가 최종 사용자의 직접 AWS 권한을 줄이는 방식은 무엇인가.
3. Product Version을 폐기할 때 이미 Provision된 Product는 어떻게 관리하는가.
4. Control Tower의 예방, 탐지와 사전 대응형 Control은 어느 시점에 작동하는가.
5. Account Factory와 AFT의 책임은 어떻게 다른가.
6. SCP, Config Rule, CloudFormation Guard와 Pipeline Policy가 중복될 때 우선순위를 어떻게 정하는가.
7. 계정 생성 요청에 포함할 필수 Metadata와 승인자는 누구인가.
