# 실습 과제

1. Request ID, Run ID, Commit SHA, Account, Region과 실행 대상 Key를 모든 Event에 연결한다.
2. CloudFormation과 Terraform에서 각각 수동 변경을 만들고 Drift를 탐지한다.
3. `failure-experiments.md`의 Worker 종료, 자격 증명 만료, 잠금 잔류와 부분 실패를 실행한다.
4. `runbooks`와 `metrics.md`를 실제 관찰 결과로 보완한다.

설계뿐 아니라 실행 가능한 예제와 검증 증거를 `submission/`에 남긴다.
